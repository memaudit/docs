memaudit's agent, `memauditd`, is a read-only host agent for measuring
cold (idle) memory, stranded DRAM, and KV-cache waste on Linux hosts. It
uses DAMON, cgroup v2, and PSI, with no eBPF and no kernel modules. This
site covers what the [main README](https://github.com/memaudit/memaudit#readme)
doesn't: the full config reference, how the pieces fit together, and
how to read what `selftest` tells you.
