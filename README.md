# memaudit docs

Source for [docs.memaudit.dev](https://docs.memaudit.dev), built with
[Astro](https://astro.build) + [Starlight](https://starlight.astro.build).

## Running locally

    npm install
    npm run dev

## Building

    npm run build   # output in dist/, also validates every internal link
